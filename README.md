### What I've (ai) built

**[sc-sp-remote](https://github.com/dekub100/sc-sp-remote)** remotely control Spotify and SoundCloud over WebSockets, no Spotify Premium required. Comes with a web interface, an OBS widget, and a Stream Deck plugin. Mostly for personal use, decided to share in case anyone else has the same needs as me.

**[TrayCell](https://github.com/dekub100/traycell)** puts the battery level of my Razer Viper V3 Pro SE and 8BitDo Ultimate 2C in a single Windows tray icon. No Razer Synapse, no 8BitDo software, no telemetry. Written in C#/.NET, built for my own setup and shared as-is.
